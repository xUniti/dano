## What is DANO?

DANO is not another productivity app. It's a **digital mirror of your life** — a single, connected space where everything you track lives together and nothing stays isolated.

Most of us scatter our lives across a dozen tools: tasks here, notes there, contacts in the phone, journaling somewhere else. DANO brings it back into one place and links it all:

- 🗓️ **The day is the unit.** A **Daily Hub** is created automatically for every day — journal, mood, energy, and reflection — and it pulls in everything you actually did: tasks completed, habits logged, people you talked to, notes you wrote.
- 🔗 **Everything is connected.** Mention a person in a note, attach a task to a project, tie a project to a goal. A universal graph keeps the links, so context is never lost.
- 🧑‍🤝‍🧑 **People are first-class.** Real relationships, not a CRM — each person has a timeline of every interaction, a strength score, and gentle follow-up nudges for birthdays and people you've gone quiet with.
- 🎯 **From intention to action.** Life **Areas** hold **Projects**, projects hold **Tasks**, and **Goals** track the progress across them — with **Habits** building the daily momentum underneath.
- ⌘ **Fast and keyboard-first.** Hit `⌘K` to search anything or create it on the spot.

## Private by design

DANO is **local-first**. Your entire life lives in a local SQLite database on your own machine — no account, no cloud, no servers, fully offline. Export a backup anytime. *(Optional cloud sync is a future, opt-in step.)*

## Run it

```bash
npm install
npm run tauri dev
```

> Built from scratch with **SvelteKit 5** + **Tauri 2** — a tiny, fast, low-maintenance native desktop app (Windows · macOS · Linux), with mobile on the roadmap.
